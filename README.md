# 🛡️ CheckMate

> **Check Before You Click**

CheckMate is a modern Website Trust & Security Analyzer built using **HTML, CSS, and JavaScript**. It helps users perform a quick analysis of any website by generating a Trust Score, checking basic security indicators, displaying SEO information, and providing an AI-style verdict through a clean and responsive dashboard.

> **Note:** This project is intended for educational and portfolio purposes. It performs client-side analysis and demonstrates how a website security dashboard works.

--

## ✨ Features

- 🔗 Website URL Analyzer
- 🛡️ Trust Score Generator (0–100)
- 🔒 HTTPS Detection
- 🌐 Domain Information
- 📈 Basic SEO Score
- 🤖 AI Verdict
- 🚦 Safe / Suspicious / Dangerous Status
- 📱 Fully Responsive Design
- 🌙 Dark Theme UI
- 🎨 Modern Glassmorphism Interface
- ⚡ Smooth Animations
- 📋 Copy Report (Optional)

## 🧠 How It Works

CheckMate performs basic client-side website analysis by:

- Validating the entered URL
- Detecting HTTPS usage
- Extracting the domain name
- Calculating a trust score using predefined security rules
- Generating a basic SEO score
- Displaying an AI-style security verdict

---

## ⚠️ Disclaimer

This project does **not** perform real-time malware scanning or phishing detection.

It is designed for demonstration and learning purposes using frontend technologies only.
